## 一次史无前例的大改（2026-08-03）

今天对博客做了一轮自搭建以来最大规模的一次修改，单项都不算难，但一次性改了这么多还是头一回。趁记忆还热，把这次改动都记下来，方便日后回头看。

> 说明：以下所有样式源码都在 `themes/yilia/source-src/css/` 下，改完需到 `themes/yilia` 目录执行 `npm run dist` 编译成 `themes/yilia/source/main.*.css`；改完主题或配置后，根目录执行 `hexo clean && hexo g` 重新生成；浏览器缓存用 `layout/_partial/css.ejs` 里的 `?ver=N` 版本号绕过。

### **一、移动端代码复制按钮变形 + 代码配色✔️**

1.移动端复制按钮（`.btn-copy`）之前样式错位变形，在 `highlight.scss` 里重做了按钮定位与尺寸，桌面/移动端都正常了。

2.代码高亮多年没配色，几乎一片黑白。在 `highlight.scss` 里补了一套 Monokai 风格的 token 配色（注释/关键字/字符串/属性/数字等），并用 `.article-entry .highlight .line .xxx` 提高优先级，确保文章内代码块生效。

```scss
// highlight.scss 节选
.btn-copy {
  position: absolute; right: 6px; top: 6px; ...
}
.article-entry .highlight .line .hljs-comment { color: #75715e; }
.article-entry .highlight .line .hljs-keyword { color: #f92672; }
.article-entry .highlight .line .hljs-string  { color: #e6db74; }
```

2.筛选交互 `filterPhotoYear()` 复用主题原有的方块按钮样式（`.photos-btn`，见 `source/dynamic/photos/ins.css`），和说说/日志/视频保持一致，没有引入新的胶囊样式。

### **三、文章结尾装饰线改短（兼容移动端）✔️**

### **四、导航页分类图标统一✔️**

1.导航页（如「开发资源 / 实用工具 / 网盘资源」）部分分类之前没有图标（图标字体里没有对应字形）。统一改用 `icon-link` 图标，五个分组全部一致。改的是 `source/tools/index.md`。

### **五、深色模式（方案B 全量）✔️**

1.这是本次最大头的一项。采用「全量覆盖」方案：定义一套 CSS 变量，在 `html[data-theme="dark"]` 下整体换肤。

2.变量与覆盖写在 `themes/yilia/source-src/css/dark.scss`，关键变量：

```scss
:root {
  --d-bg: #1e1e1e; --d-card: #2a2a2a; --d-text: #d8d8d8;
  --d-text-sub: #a8a8a8; --d-text-strong: #ffffff;
  --d-border: #3a3a3a; --d-link: #6db3f2;
}
html[data-theme="dark"] {
  body { background: var(--d-bg); color: var(--d-text); }
  #header a { color: var(--d-text); }
  .nav-group-title { color: var(--d-text-strong); }
  #footer { color: var(--d-text); opacity: .85; }
  ...
}
```

3.为避免刷新瞬间白屏闪烁，在 `layout/_partial/head.ejs` 里加了防闪烁脚本，在 `<head>` 最前面根据 localStorage / 系统偏好先定好主题：

```html
<script>
(function(){
  var t=null;
  try{ t=localStorage.getItem('theme'); }catch(e){}
  if(!t){ t=(window.matchMedia&&window.matchMedia('(prefers-color-scheme: dark)').matches)?'dark':'light'; }
  document.documentElement.setAttribute('data-theme', t);
})();
</script>
```

### **七、回到顶部功能修复✔️**

1.点回到顶部没反应，原因是 yilia 的滚动容器是 `#container` 而不是 `window`。JS 里改为同时尝试 `window / document.body / #container / .mid-col` 多个滚动目标，确保能滚到顶。

2.回到顶部箭头图标改成和主按钮一致的白色「+」风格；移动端 github / 微博 / QQ 背后的色块去掉（`#mobile-nav .overlay` 透明）；「赏」按钮文字也改成白色。

### **八、深色模式文字颜色统一审查✔️**

1.全站扫了一遍深色模式下发暗的文字，统一提亮：导航页分类标题与描述、页脚、文章内日期与阅读量、说说时间线等，全部对齐到 `--d-text / --d-text-strong`。

2.ID 级选择器（`#header a`、`.left-col #header .profilepic`）必须在 `dark.scss` 里用同级 ID 优先级覆盖才生效；移动端遮罩是 EJS 内联样式，需加 `!important`。

### **九、移动端分隔线统一为实线✔️**

1.移动端每个主页面 / 文章 / 菜单分类顶部那条虚线不需要，去掉（删 `mobile.scss` 里 `.article-header` 的 `border-bottom:1px dotted`）。

2.文章、友链等所有虚线分隔统一改成实线（`tools.scss` 里 `.search-li` 用 `1px solid`），和全站风格一致。

### **十、动态说说时间线 + 页面装饰竖条✔️**

1.说说时间线的蓝色圆点没和竖线、日期圆点对齐，在 `source/dynamic/shuoshuo/timeline.css` 里把 `.timeline-dot` 的 `left / top` 校准（`left:-26px; top:7px`）。

2.每个页面左上角的竖条装饰线改成亮色（深色模式下 `border-left-color` 用亮灰 `#8a8a90`）。

### **十一、文章目录（TOC）改为全站显示，并清理旧 BUG✔️**

1.主题配置 `themes/yilia/_config.yml` 里 `toc` 由 `0` 改为 `2`（`2` 表示所有文章均显示目录，无需逐篇写 `toc:true`）。

```yaml
# 目录设定：0-不显示目录； 1-文章 md 里 toc:true 才有； 2-所有文章均显示目录
toc: 2
```

2.之前「重来」等文章左上角残留「文章目录」字样，是旧版 `article.ejs` 里一段 inline TOC 代码（带 `show-toc-btn / toc-title / 文章目录` 的脚本）造成的 BUG。那段代码已**整体删除**，现在目录统一由 `layout/_partial/aside.ejs` 渲染（hover 悬浮 tooltip 形式），干净无残留。

> 注：个别文章（如《yilia主题配置与使用》）正文里仍保留当年手搓 TOC 的 CSS/JS 教程示例，那只是文章文字，不会被当作站点逻辑执行，不影响网站。

### **十二、搭建动态内容中心（说说 / 相册 / 视频 / 日志）✔️**

1.「动态」是一个聚合页（访问 `/dynamic`），顶部用方块按钮在四个模块间切换：说说、相册、视频、日志。这些模块都是「数据驱动」的纯前端实现——不用写文章，改 JSON 就能更新内容，非常适合放碎片化的日常记录。

2.统一入口 `source/dynamic/index.ejs` 负责 tab 切换，并默认加载「说说」时间线：

```html
<!-- source/dynamic/index.ejs 节选 -->
<div class="photos-btn-wrap">
  <a class="photos-btn active" href="javascript:void(0)">说说</a>
  <a class="photos-btn" href="./photos/">相册</a>
  <a class="photos-btn" href="./videos/">视频</a>
  <a class="photos-btn" href="./log/">日志</a>
</div>
<script>
  // 用 XHR 拉取 ./shuoshuo/data.json，渲染到 #timeline
</script>
```

3.说说（shuoshuo）：竖向时间线，数据在 `source/dynamic/shuoshuo/data.json`，由 XHR 拉取后渲染到 `#timeline`。`timeline.css` 控制蓝点 / 竖线样式（今天已校准圆点对齐，见第十节）。

```json
// source/dynamic/shuoshuo/data.json
{
  "list": [
    { "date": "2026-08-03", "content": "博客大改完成，重来！" },
    { "date": "2026-08-01", "content": "今天加了深色模式" }
  ]
}
```

4.相册（photos）：按年份分组展示，今天新增了年份时间轴筛选（见第二、十节）。数据在 `source/dynamic/photos/data.json`，每条支持 `image` / `video` 两种类型：

```json
// source/dynamic/photos/data.json
{
  "list": [
    {
      "year": 2024,
      "arr": {
        "link": ["/assets/xxx/a.jpg", "/assets/xxx/b.mp4"],
        "type": ["image", "video"],
        "text": ["记账截图", "日常片段"]
      }
    }
  ]
}
```

5.视频（videos）：iframe 嵌入（B 站等），数据在 `source/dynamic/videos/data.json`，每条含 `src` / `title`：

```json
// source/dynamic/videos/data.json
{ "list": [ { "src": "https://player.bilibili.com/...", "title": "标题" } ] }
```

6.日志（log）：另一条时间线样式（jazz-timeline），数据在 `source/dynamic/log/data.json`，结构和说说一致。

7.扩展方法（给网友参考）：要更新内容，只改对应 `data.json` 的 `list` 数组即可，不用碰布局代码；想加新模块，复制 `source/dynamic/` 下任一文件夹，再在 `index.ejs` 里补一个 tab 就行，零构建、纯静态。

### **十三、导航页（/tools/）✔️**

1.导航页是一个独立的自定义页面（访问 `/tools/`），挂在顶部菜单里。在 `themes/yilia/_config.yml` 的 `menu:` 加一行即可出现入口：

```yaml
menu:
  主页: /
  归档: /archives/index.html
  分类: /categories
  动态: /dynamic
  导航: /tools/
```

2.页面用 `layout: tools` 渲染（`themes/yilia/layout/tools.ejs` + `_partial/tools.ejs`），正文写在 `source/tools/index.md`。内容按「分组」组织，每个分组有标题、分隔线、描述和若干链接：

```html
<!-- source/tools/index.md 节选 -->
<div class="nav-group g-1">
  <span class="nav-group-title">我也在这里</span>
  <hr class="nav-divider">
  <p class="nav-group-desc">我的其他个人主页与社交账号，欢迎来撩。</p>
  <div class="nav-links">
    <a class="nav-link" href="https://github.com/durian" target="_blank">
      <i class="icon icon-link"></i>GitHub</a>
    ...
  </div>
</div>
```

3.目前有 5 个分组：我也在这里、网盘资源、实用工具、跳转链接、开发资源。所有链接图标统一用 `icon-link`（今天修过，之前部分分组缺图标，见第四节）。

4.扩展方法（给网友参考）：加一个新分组就复制一个 `<div class="nav-group">` 块，改 `nav-group-title` / `nav-group-desc` 和里面的 `<a>` 即可；想换图标，把 `icon-link` 换成主题图标字体里的其它字形。
